# Task1-HTML-Internship
Designed a webpage layout using only HTML semantic tags and CSS without using any &lt;div> elements. The layout includes a Header, Navigation Menu, Left Sidebar, Main Content Area, Right Sidebar, and Footer, arranged to match the provided design using semantic tags such as &lt;header>, &lt;nav>, &lt;main>, &lt;aside>, &lt;section>, and &lt;footer>.
